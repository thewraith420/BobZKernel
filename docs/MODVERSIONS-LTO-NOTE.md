# MODVERSIONS + LTO Incompatibility

## Issue
`CONFIG_MODVERSIONS=y` is **incompatible** with `CONFIG_LTO_CLANG_FULL=y` when building DKMS modules (nvidia, LenovoLegionLinux, etc.).

## Symptoms
- DKMS builds fail with "Error! Bad return status for module build"
- Modules fail to load with "disagrees about version of symbol module_layout"
- Build logs show genksyms failures with `-fno-lto -flto` conflicts

## Solution
**Always disable MODVERSIONS when using LTO:**
```
# CONFIG_MODVERSIONS is not set
```

## Why
- LTO generates symbol versions differently than traditional compilation
- External modules (DKMS) can't match the symbol CRCs generated by LTO kernel
- The `-fno-lto -flto` flag conflict breaks genksyms during DKMS builds

## Applied
Both `configs/.config-6.14` and `configs/.config-6.18` have been updated with `CONFIG_MODVERSIONS` disabled.
